* Learning TypeScript for Interview

I found some design features of TypeScript to be puzzling: 

- ~const~ is not really a constant (You cannot update there object reference, but you can update the object itself).
- The ~extends~ keywords acts like a subtype relation. However, the meaning seems to differ depending on what type is on the right hand side, and often produce a relation that does not match the connotation of /"extends"/.

I believe it is possible to get used to many of the quirks. Furthermore, TypeScript has to be compatible with JavaScript while maintaining some sense of safety, a really tall order. What it has managed to achieve is already impressive.
